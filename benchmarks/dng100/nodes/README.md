# Network node lists

One body ID per line: the neurons that form each simulated front-leg network. Membership follows the
published networks of Pugliese et al. (repository smpuglie/Pugliese_2026 @ 10e7661, files pinned by SHA-256 in
`benchmarks/dng100_walking_cpg/reproduce_manc_connectivity.py`). These lists define WHICH neurons are simulated;
they carry no information about which of them matter. Everything else in the bundle is derived from BrainIR builds.
