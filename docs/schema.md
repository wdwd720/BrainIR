# BrainIR canonical schema (v0.2.0)

> Generated by `scripts/gen_schema_docs.py` from `src/brainir/schema/`. Do not edit by hand.

## Principles

1. **Namespacing.** Every record belongs to one `(dataset, dataset_version)`. The global neuron key is
   `neuron_uid = "<dataset>:<version>:<source_id>"`. Native integer IDs are unique only inside one release:
   MANC and MaleCNS share 19,344 integer body IDs that denote different neurons, and CAVE root IDs change with edits.
2. **Evidence kinds are explicit.** Every column carries Arrow field metadata `evidence` (below), so a predicted
   neurotransmitter can never be mistaken for measured physiology, and anatomy is never mistaken for a model
   parameter.
3. **Anatomy is not strength.** `synapse_count` counts T-bar→PSD pairs. There is **no** `weight` column anywhere in
   the anatomy tables. Effective weights are `ModelParameter` records owned by a model.
4. **Hypotheses are computed, not stored.** Excitatory/inhibitory sign is derived on demand from predicted
   neurotransmitters under a versioned rule (`brainir.sign.conventional-v1`) and always reported with that rule ID.
5. **Nothing is silently dropped.**
   - Synapses outside primary neuropils go to `<unassigned>`.
   - Autapses are flagged, not removed.
   - Connectivity to non-neuron fragments is kept in per-neuron totals.

## Evidence kinds

| kind | meaning |
|---|---|
| `identifier` | Keys and namespacing (dataset, version, IDs). Not a biological claim. |
| `em_reconstruction` | Derived from the EM volume (proofread segmentation + automated synapse detection above a confidence threshold). Anatomical estimate, not physiological strength. |
| `derived_anatomy` | Deterministic BrainIR function of EM-derived fields (e.g. is_autapse, dominant neuropil, totals). Same caveats as em_reconstruction. |
| `curated_annotation` | Expert-assigned labels (type, class, side, hemilineage, status, cross-dataset matches). Human judgements; may change between releases. |
| `ml_prediction` | Machine-learning model output with a model-reported confidence (e.g. NT from EM). |
| `literature_label` | Label transferred from published experiments (e.g. known NT of a cell type); not measured in this animal. |
| `derived_hypothesis` | Hypothesis from an explicit, versioned BrainIR rule (e.g. sign from predicted NT). Never ground truth. |
| `model_parameter` | Assumed or fitted parameter of a computational model (effective weight, time constant). Never stored in anatomy tables. |
| `experimental_measurement` | Physiological or behavioural measurement from a real experiment. |
| `provenance` | Metadata about where data came from and how it was transformed. |

## Sign rule `brainir.sign.conventional-v1`

| NT | sign | class | rationale |
|---|---|---|---|
| acetylcholine | +1 | conventional_fast | Fast cholinergic transmission in the fly CNS is predominantly nicotinic (excitatory); muscarinic receptors (mAChR-A/B) can mediate inhibitory/modulatory effects. |
| gaba | -1 | conventional_fast | GABA-A (Rdl) chloride channels and GABA-B receptors are inhibitory. |
| glutamate | -1 | context_dependent | Central glutamatergic inhibition via GluCl-alpha chloride channels is common in flies, but ionotropic (excitatory) glutamate receptors also exist (e.g. NMJ, some central synapses). |
| histamine | -1 | context_dependent | Histamine-gated chloride channels (HisCl1, ort) are inhibitory; mostly visual system. |
| dopamine |  | modulatory | Metabotropic neuromodulator; no fast sign. |
| serotonin |  | modulatory | Metabotropic neuromodulator (5-HT7 etc. aside); no fast sign. |
| octopamine |  | modulatory | Metabotropic neuromodulator; no fast sign. |
| unclear |  | unknown | Neurotransmitter prediction ambiguous. |
| unknown |  | unknown | Classifier assigned the 'unknown' class. |

### `connections`

Directed neuron->neuron connections aggregated from synapses (both endpoints in NEURONS).

Primary key: `pre_id, post_id` · sort order: `pre_id, post_id`

| column | type | null | evidence | unit | description |
|---|---|---|---|---|---|
| `pre_id` | `int64` | no | identifier |  | Presynaptic neuron source_id. |
| `post_id` | `int64` | no | identifier |  | Postsynaptic neuron source_id. |
| `synapse_count` | `int32` | no | em_reconstruction | count | Number of synaptic connections = T-bar->PSD pairs (polyadic synapses: one T-bar may contribute several pairs) with confidence >= threshold (neuPrint 'weight'). Anatomical, NOT a physiological strength. |

| `all_parents` | `list<item: string>` | yes | curated_annotation |  | Every parent of the ROI in the hierarchy DAG. |
| `depth` | `int16` | yes | curated_annotation |  | Minimum depth in the hierarchy (root = 0); null if absent. |

## Record models (pydantic, `brainir.schema.models`)

**Core records**
- `DatasetVersion`: dataset, version, release date, animal sex, CNS coverage, acquisition source and method,
  timestamps, checksums, transformations, synapse-confidence thresholds, coordinate space, voxel size, citation,
  license.
- `Neuron`: identity plus curated annotations, `NeurotransmitterPrediction` (ML), `SignHypothesis` (rule-derived),
  neuropil counts, verbatim source annotations, `MorphologyRef` (skeleton/mesh URIs), and `Provenance`.
- `DirectedConnection`: `synapse_count`, `synapse_count_hp`, `is_autapse`, per-neuropil counts and an optional
  `predicted_sign` (the presynaptic neuron's hypothesis; Dale's principle assumed). It has **no weight field**.
- `Synapse`: pre/post locations, detector confidences, neuropil.
- `ModelParameter`: a parameter of a named model, with `origin ∈ {assumed, fitted, derived_from_anatomy}` and its
  derivation.

**Future experiments.** `Experiment` → `Trial` → `Intervention` / `Measurement` / `TimeSeries` / `TargetSpec`.
- Interventions cover optogenetic, thermogenetic, chronic, genetic, pharmacological, electrical, sensory and
  in-silico cases.
- Targets name cell types and neuron UIDs, and also the driver line with a mapping confidence (a genetic line is
  not a neuron).

## Accommodating other connectomes (planned tables; see research/data_ecosystem.md)

| need | planned representation |
|---|---|
| CAVE root-ID churn (FlyWire, BANC, FANC) | `neuron_anchors` (supervoxel / nucleus / anchor point per materialization) + `id_lineage` (old→new) |
| detector / filter as part of version | `DatasetVersion.synapse_table_id` + filter parameters; edges stored unthresholded |
| different neuropil sets and assignment rules | long `connection_neuropils` table + per-dataset ROI catalogue with `all_parents` (DAG) |
| NT class sets and aggregation methods differ | `nt_prediction(level, class_set, class, prob, method, model_id)` long table |
| cross-dataset identity | `cross_dataset_matches(key_a, key_b, level, method, score, source)` (many-to-many) |
| no canonical type ontology | `canonical_types` (synonyms, FBbt IDs) + raw→canonical vocabulary maps with provenance |
| same specimen, several datasets (optic-lobe ⊂ MaleCNS) | `specimen_id` on `DatasetVersion` |
